# login-page-ui

A standalone, frontend-only login experience crafted with React.

## Available Scripts

- `npm install` to download dependencies.
- `npm run start` to launch the development server at http://localhost:3000.
- `npm run build` to produce a production-ready build in the `build/` folder.
- `npm run test` to run the default React scripts tests.

The project uses Create React App conventions to keep the tooling simple while showcasing a refined login card component.
